====================================================
       PALINDROME LINKED LIST - PROBLEM STATEMENT
====================================================

OVERVIEW
--------
Given a singly linked list, check whether the linked list
is a palindrome or not.

A palindrome linked list is a list that reads the same
forward and backward.

Return:
  - "Yes" if the linked list is palindrome
  - "No"  otherwise


====================================================
INPUT FORMAT
====================================================
- First line  : integer N (number of nodes)
- Second line : N space-separated integers
                (linked list elements)


====================================================
OUTPUT FORMAT
====================================================
- Print "Yes" if the linked list is palindrome
- Otherwise print "No"


====================================================
CONSTRAINTS
====================================================
1 <= N          <= 10^5
1 <= Node Value <= 10^9


====================================================
SAMPLE INPUT
====================================================
5
1 2 3 2 1


====================================================
SAMPLE OUTPUT
====================================================
Yes


====================================================
EXPLANATION
====================================================
Linked list : 1 -> 2 -> 3 -> 2 -> 1

Reads same from both directions.
Hence, it is a palindrome linked list.

Forward  : 1 2 3 2 1
Backward : 1 2 3 2 1
Result   : Yes


====================================================
SOLUTION - Source.java
====================================================

import java.util.*;

public class Source {

    static class Node {
        int data;
        Node next;

        Node(int data) {
            this.data = data;
        }
    }

    // Function to check palindrome
    static boolean isPalindrome(Node head) {

        ArrayList<Integer> list = new ArrayList<>();

        Node temp = head;

        // Store linked list values
        while (temp != null) {
            list.add(temp.data);
            temp = temp.next;
        }

        int left  = 0;
        int right = list.size() - 1;

        // Compare from both sides
        while (left < right) {
            if (!list.get(left).equals(list.get(right))) {
                return false;
            }
            left++;
            right--;
        }

        return true;
    }

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        if (n == 0) {
            System.out.println("No");
            return;
        }

        // Create linked list
        Node head = new Node(sc.nextInt());
        Node temp = head;

        for (int i = 1; i < n; i++) {
            temp.next = new Node(sc.nextInt());
            temp = temp.next;
        }

        // Check palindrome
        if (isPalindrome(head)) {
            System.out.println("Yes");
        } else {
            System.out.println("No");
        }
    }
}


====================================================
APPROACH EXPLANATION
====================================================

Technique : ArrayList + Two Pointer
----------

Step 1: Traverse the linked list and store all
        node values in an ArrayList.

Step 2: Use two pointers:
          - left  starting from index 0
          - right starting from last index

Step 3: Compare values at left and right:
          - If mismatch found --> return false
          - Move left++ and right--
          - Repeat until left >= right

Step 4: If all values match --> return true

----------------------------------------------------
EXAMPLE WALKTHROUGH
----------------------------------------------------
List     : 1 -> 2 -> 3 -> 2 -> 1
ArrayList: [1, 2, 3, 2, 1]

Step     | left | right | list[left] | list[right] | Match?
---------|------|-------|------------|-------------|-------
  1      |  0   |   4   |     1      |      1      |  Yes
  2      |  1   |   3   |     2      |      2      |  Yes
  3      |  2   |   2   |   left >= right -> Stop  |

Result: Palindrome -> "Yes"

----------------------------------------------------
Time Complexity  : O(N)
Space Complexity : O(N)  -- ArrayList storage
